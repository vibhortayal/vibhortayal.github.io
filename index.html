Principles

How I work

01

Prove the risky part first.

For LineCall I built the vision prototype before the app. If the core idea doesn’t work, nothing else matters.

02

Never invent. Stay silent when uncertain.

The app only yells calls it’s confident about. Same rule for every project: no fake data, every estimate labeled.

03

Describe, don’t code.

I spec it in plain words from my phone. Muse builds, the cloud deploys, I test. The whole loop fits in an evening.
